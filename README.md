# Khu vườn hóa đá

Ấn phẩm web lưu trữ kỷ niệm ba năm cấp ba của tập thể lớp **12 Chuyên Hóa** (niên khóa 2023–2026), chạy hoàn toàn miễn phí trên **GitHub Pages**.

## Điểm nổi bật
- **Trang công khai thuần tạp chí (`/`):** Mở link là đọc và xem ngay, chia 3 mục riêng biệt **Lớp 10 — Lớp 11 — Lớp 12**, không bình luận, không tương tác, không lộ nút đăng nhập hay đăng bài.
- **Đăng bài kiểu post Facebook (thuần đọc):** Hỗ trợ viết câu chuyện tự do, tải lên nhiều ảnh cùng lúc, đăng video ngắn (tối đa 20MB), và chế độ **Che mờ ảnh dìm** (bấm để bóc niêm phong).
- **Quản trị nội bộ tách biệt:** Đường dẫn biên tập và thông tin truy cập chỉ được chia sẻ nội bộ cho quản trị viên và các thành viên được cấp quyền đăng bài.

## Chạy cục bộ
```bash
npm install
npm test
npm run dev
```
